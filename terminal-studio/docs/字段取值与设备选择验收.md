# 字段取值与设备选择

2026-10-20

## 操作

- 公共头、普通字段和数组子字段的值旁边，可以选择固定值、自动流水号、当前会话、报文总长、时间戳、最近接收字段或自定义表达式。
- “最近接收字段”只填写字段名，不手写花括号。接收值尚不存在时，沿用引擎原有错误处理。
- 设备图标打开全部系统的设备列表，可按名称、标识或系统搜索。选择设备后，再选择要填入的属性。
- 设备属性复制为当前字段的固定值，不是随设备档案变化的动态引用。不同系统间不自动推断地址与序列号的对应关系。
- 按属性原有编码转换为目标字段编码，溢出或缺少原始属性定义时禁止选择，不截断地址。
- 已绑定字典的字段，在选择设备属性或切换自动取值来源时解除字典绑定；菜单内有提示。
- 旧表达式保持原样，显式长度（如 `{seq:2}`）在未编辑时不被重写；复杂表达式仍可通过自定义表达式编辑。

## 验证

- `npm run build`：TypeScript 与前端构建通过。
- `scripts/ui_field_value_source.cjs`：取值来源、旧表达式往返、跨系统设备搜索、属性选择、字典解绑、编码转换与超长值拦截通过。
- 原生 EXE 连接备份数据，公共头显示中文取值来源；设备菜单显示两个系统下的全部 5 台设备。
