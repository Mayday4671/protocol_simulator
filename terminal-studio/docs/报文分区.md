# 报文解析分区

在“协议管理”编辑字段，展开该行的齿轮设置，可以选择“所属分区”：自动、公共头、扩展头、净荷、尾部。分组公共头的字段也使用同样的设置。

“分区名称”可选。需要区分多个头时，分别填写“公共头 A”“公共头 B”。同一名称的连续字段显示在同一区域；A、B、A 按实际先后显示为三段，不重新排序或合并。

自动模式按定义来源处理：分组公共头中的字段属于公共头，协议正文中的字段属于净荷。不会根据字段名、信令码、CRC算法或固定字节位置猜测头尾。没有头尾的协议只显示净荷；没有配置尾部时不凭空增加尾部。

XML 中对应 `section` 和 `section-name`，取值如下：

```xml
<field name="版本" len="1" enc="hex" value="01"
       section="header" section-name="公共头 A" />
<field name="路由域" len="4" enc="hex" value="00000001"
       section="header" section-name="公共头 B" />
<field name="参数" len="2" enc="hex" value="1234" section="payload" />
<field name="结束标记" len="3" enc="hex" value="EE0D0A" section="trailer" />
```

扩展头使用 `section="header_extension"`。省略 `section` 表示自动。数组子字段默认继承数组分区，XML 可显式覆盖。公共头覆盖字段只有显式指定的分区属性才覆盖原定义。

分区只控制解析展示，不改变字段顺序、编码或业务规则。字节范围来自实际报文，条件未选中的字段不占范围；动态数组按实际条目分组。字段不足时标注缺失，超出定义的字节显示为“未解析”，不会将其标成校验通过。

字段卡片同时显示字段名、HEX、十进制值和已定义的字典含义。点击可固定查看，Esc 先取消固定，再关闭详情；复制与解析文本中的偏移使用同一组实际字节范围。

点击分区标题可折叠或展开，也可使用右上角的“全部折叠”“全部展开”。折叠后保留名称、字节范围、字段数和总长度；点击顶部的分区标签会展开并定位到该分区。各段独立折叠，多个同名头不会一起收起。切换报文后默认全部展开，复制解析仍包含全部字段。

公共头使用蓝色，扩展头使用紫色，净荷使用青绿色，尾部使用琥珀色；同类不同名称使用稳定的色阶。同名段在不同报文中保持相同色阶，分类仍由协议定义决定。

字段卡片使用六色色条和浅色底区分相邻字段；同一数组各条记录中的同名字段保持同色，便于对照。字段颜色仅用于视觉区分，不表示成功、失败或业务状态。HEX 作为主值显示，十进制值单列，字典含义显示为紧凑标签；固定查看的字段显示图钉。
