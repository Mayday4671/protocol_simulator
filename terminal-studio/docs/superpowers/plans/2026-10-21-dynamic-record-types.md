# 动态关联资料实施计划

目标：按系统维护自定义资料类型，任意请求协议可将成功应答转换为资料更新或删除；电话是普通关联类型，不再写死业务。

设计：类型定义包含稳定标识、显示名、属性名称、是否必须关联设备、唯一标识范围。设备档案继续使用原有表；其他类型共用业务资料表。旧类型按现有规则兼容，编辑后使用显式类型定义。协议字段仍决定编码和长度，资料定义不重复通信结构。

- [x] 核心：新增操作和设备内标识范围，测试相同编号不同设备、删除不依赖属性。
- [x] 存储：类型 CRUD、被引用删除保护、设备范围唯一索引、保存/删除事务与类型变更检测。
- [x] XML：携带系统级类型定义及操作，旧文件兼容。
- [x] 客户端：业务资料内管理类型，规则引用类型并选择操作，按系统/类型/设备筛选。
- [x] 验证：Rust、构建、客户端配置与真实 UDP 新增/删除，生成安装包。生产数据不修改。

已有类型的关联策略或唯一范围被规则/记录引用后不得直接改动；须先解除引用，避免悄悄重解释旧数据。删除属性若仍被映射或资料使用，提示具体引用。类型改名只改显示名。
