# 右侧流程进度抽屉

用户提供明确参考：交互控制台右侧默认折叠，点击滑出，以纵向时间轴展示流程。沿用现有主题，不改变 Rust 执行、关联或入库规则。

- [x] 回归脚本先覆盖默认折叠、展开/关闭、无流程/无通道、真实运行状态、历史记录、报文入口和页面操作不被遮罩阻断。
- [x] FlowConsoleTracker 移除占据表单空间的横条和全屏流程图；右侧入口打开宽约 380px 的非模态抽屉。抽屉包含流程选择、启动/停止、运行选择和时间轴；Esc 收起，关闭不停止运行。工作区隐藏时入口和抽屉隐藏。
- [x] 新建 FlowTimeline：按照运行快照列出步骤，圆点/对勾/时钟与文字区分状态；当前步骤突出，未执行灰色。展开步骤显示每次执行的实际事件，点击报文沿用分区解析。支持跟随当前步骤并允许关闭跟随。循环尝试保留在步骤明细。
- [x] 复用 Rust 跟踪记录，不合成状态或报文。当前通道隔离运行记录；切换流程/通道时清理展开的报文，选择旧记录不影响后台任务。
- [x] 浏览器针对性测试、TypeScript、构建，隔离数据库最终 EXE 实际 UDP 验收，浅/深色及小窗口核对。生成新的 NSIS 安装包，不覆盖安装用户客户端。
