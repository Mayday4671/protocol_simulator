# 流程测试可视化

用户已确认：保留流程配置，以实际信令驱动进度图，支持自动执行和手动收发跟踪；点击步骤查看报文解析，并提供收发时序。

技术：现有 ReactFlow、React、Tauri、Rust UDP 和 SQLite 日志。沿用基座主题和紧凑布局，不修改用户数据。

- [x] Rust 跟踪模型：运行快照、时间戳、步骤尝试、实际日志引用、分支、等待和终止状态。最近 50 次已结束运行保留在本次应用会话，单次事件上限 2000，显示截断计数。
- [x] 执行与观察共用匹配逻辑：明确通道，校验协议系统；发送前日志水位防止快速回包漏配；关联字段支持显式请求/应答字段对，默认识别关联序号和反向设备地址。无关联序号需明确选择串行匹配。其他对端、错误序号与其他信令不推进步骤。
- [x] 手动跟踪：观察指定通道新产生的发送/接收；支持被动接收步骤；不发送任何报文；停止和超时有明确结果。
- [x] 测试视图：流程图状态、实际经过的边、等待时间；步骤报文及全程时序，复用 DatagramDetail 分区解析；运行选择和显式通道选择。配置视图保留。
- [x] 验证：关联误配、快速应答、手动跟踪、超时/失败分支、停止、切页恢复；真实本地 UDP + 隔离数据库进行客户端验证；前端构建、Rust 回归；生成 NSIS 安装包，不关闭用户客户端。

匹配到报文和业务成功是两回事。现有结果判定兼容保留，新增可配置结果字段/成功值。图中完成表示流程执行结束，若步骤出现失败/超时，运行摘要不能显示全部成功。
