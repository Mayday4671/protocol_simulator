# 显式应答保存规则

用户已授权：应答成功后按配置保存设备、电话（关联设备）及其他资料。

1. 独立规则表，以请求协议为主键；默认无规则，不写业务资料。
2. 规则包含应答协议、成功字段/值、请求/响应数组、按序或按标识对应、唯一标识、属性映射、所属设备、关联流水号、超时。
3. 无流水号须显式选择串行模式；禁止并发等待同一个应答，超时后须重新启动监听。协议无法区分成功后的迟到重复包，这一限制必须在界面说明。
4. 仅保存已发送字节的快照。验证同通道/系统/对端/应答，按规则成功值逐条写入。数组数量、唯一键、关联设备不合法则本次事务不提交。
5. 通用业务资料表保存类型、唯一标识、属性、设备关联、来源与更新时间。设备同步到原设备档案，电话与其他资料在设备管理的业务资料页查看。
6. 关闭旧隐式配置提交与会话创建设备；会话仍允许更新已有设备。
7. XML 导入导出保留规则；界面提供字段下拉、规则校验、资料查看。
8. 验收：设备逐项成功/失败，电话关联，普通应答不写入，错误流水/对端/数量、超时、重复包、缺失设备、重复标识拒绝；真实 UDP；前端与 Windows 安装包。

不修改用户当前协议业务值或成功码，规则由用户显式录入。
