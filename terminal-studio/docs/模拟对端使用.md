# 无人机本机模拟对端

启动：双击 `scripts/启动模拟对端.cmd`，或运行 `python scripts/musp_peer.py`。默认监听127.0.0.1:39002；客户端通道本地39001、目标39002。已经有对端运行时不要重复启动。

支持的本次测试场景：
- 0x21→0x22：校验条目数/大小，按条目返回AA；配置应答模拟，不模拟真实硬件提交或资源分配。
- 0x01→0x02→0x03→0x04：无需认证的注册。默认预配置设备地址00003B，许可会话从1234开始，许可3600秒；确认回填会话、使用新事务号。
- 注册完成后0x31→0x32：回填请求事务和会话，返回当前时间。
- 其他信令、非法会话、错误CRC、错误长度均日志REJECT，不伪造成功报文。认证扩展只作结构检查；没有实现认证模式1或Token认证。

配置请求0x21支持修改条目数、条目内容、事务号后直接发送，长度和CRC自动计算；0x22返回相同数量的AA。其余协议仍为静态CRC样例。注册与心跳按以下默认值验证：
1. 0x21设备配置请求（可单独验证配置）。
2. 0x01开机注册请求，许可返回会话1234。
3. 0x03注册确认：展开公共头，事务序号改为00000066，CRC改为BF7E，会话保持1234，再发送。
4. 0x31心跳请求。

上述第三步CRC仅适用于当前默认示例其他字段不变。改其他值须重算CRC，对端会拒绝坏CRC。重新注册得到其他会话后必须使用新会话并重算CRC。相同请求重传返回缓存应答，不重复推进注册。

可配置：`--port 39002`、`--bind 127.0.0.1`、`--config-common8 off`（不带8B通用段的配置模板）、`--session-start 0x1234`、`--device 0x3b`（可重复指定）、`--log 路径`。
