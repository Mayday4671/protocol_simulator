# 控制台字段设备选择

交互控制台顶部仅保留系统、分组、协议、通道。设备从公共头或净荷的具体字段中选择，不再有整张报文共用的设备选择框。

- 字段用途为「源设备」「目标设备」「设备序列号」，或配置了设备属性 Key 时，字段提供设备档案选项。字段名称可自行命名，不根据中文名称猜测用途。
- 可选项来自所有系统的设备档案，显示名称、字段值、所属系统；只显示能按该字段编码、长度填入的档案，不截断地址。
- 选择源设备时填入源标识，并按显式属性 Key 填入相关属性。选择净荷中的属性时填入对应属性及其他已映射属性。目标设备只改变目标字段，不替换发送方、会话或发送方属性。
- 数值根据档案属性定义转换 HEX / 十进制，文本按字节长度校验。映射属性不存在时清空该属性，转换失败时整次填入不生效并提示原因。
- 填入后仍可手动修改。单次发送和定时发送使用当前表单值；会话及流水号继续由实际源标识和原有自动规则处理，长度及校验字段保持自动计算。
- 不修改已有协议定义、通道、字典或设备档案。新增协议需配置字段用途或属性 Key，普通字段不会自动绑定设备。

验证：`scripts/test_device_selection.cjs` 验证映射、编码和源/目标隔离；`scripts/ui_console_devices.cjs` 验证真实组件、重复地址选项、表单编辑及提交值；`scripts/native_console_devices.cjs` 使用隔离数据库和实际 UDP 对端验证桌面 EXE 注册、查询、会话及发送字节。
