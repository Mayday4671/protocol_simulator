# MUSP 桌面联调工作区重构

用户要求直接重构现有客户端。依据本轮用户截图：项目操作挤占侧栏、单列长表单、卡片嵌套、自动字段像可编辑字段、发送与接收需滚屏、说明文案冗余。

选择：紧凑工业工具布局。仅换皮不能解决滚动链；向导不适合反复联调。保留现有已验证业务引擎，工作台用并列操作与反馈区。

- [x] Sidebar / WorkspaceTabs / Workspace：窄导航、顶部项目与系统、项目菜单；全局蓝灰/青色焦点，明确层级和键盘焦点。
- [x] Console / Fields：顶部传输设置，左侧字段，右侧报文；底部固定编码发送；自动字段折叠为摘要，去重复说明。就地启动已选通道。
- [x] Packets：紧凑报文列表与解析区，自动跟随最新、选中冻结，HEX/字段在同一处；暂停与分页保持功能。
- [x] Flows：默认运行调试，编辑模式单独呈现画布与节点配置，减少首次操作负担。协议字典采用信令索引与详情。
- [x] 客户端截图检查 1360×860 和 1024×700、明暗主题；20 项真实 UDP 流程回归。
- [x] NSIS 安装后复测：用户关闭旧版后完成独立安装；最终包 20 项交互、画布切换、两种尺寸、主题与重启检查通过。

不修改协议、默认业务值或状态机，不增加独立资源页面。字段来源仍显式指定。错误、未保存确认、禁用原因保留；正常状态不堆砌实现说明。默认工作区保留旧格式兼容入口在项目菜单中。
