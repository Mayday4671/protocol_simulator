# XML 编辑器重构

目标：解决输入文本与高亮错位、长文档编辑卡顿；保留当前 XML 导入格式、公共头、字典和协议业务规则。

设计：采用开发文档指定的 Monaco。编辑器与 Worker 本地打包，打开 XML 时加载；由同一文本模型处理光标、高亮、行号和滚动。沿用当前深浅主题，紧凑工具栏提供查找、替换、折叠和换行。XML 语法校验停顿 300ms 后执行，中文组合输入期间暂停；应用时立即复核最新内容。

备选：继续同步 textarea/pre 无法消除两个排版面；CodeMirror 也可满足需求，但本项目已有 Monaco 技术约定。选择 Monaco。

步骤：

1. 复现旧编辑器：孤立 `<` 被高亮器漏掉，记录文本/光标/滚动证据。
2. `XmlEditor.tsx` 接入独立模型，释放模型和监听器；`monacoXml.ts` 只引入 XML 与所需编辑功能；`xmlValidation.ts` 集中语法与行列诊断。
3. `ProtocolXmlDialog.tsx` 独立管理导出、应用与失败，避免每次输入重绘整个协议页面；应用前读取当前模型，语法错误禁止提交，部分导入失败保留源稿。
4. `ui_xml_editor_regression.cjs` 验证长行/780 行定位、输入/撤销/中文组合、搜索替换/折叠、错误定位、主题/窗口变化、模型释放。
5. 构建前端与 Windows EXE；用独立数据库副本验证真实导出/编辑/应用/重新打开，检查离线资源与最终界面，生成 NSIS 包并记录结果。

不自动格式化或改写业务数据，不更改已有导入合并规则，不覆盖用户运行中的程序或数据库。
