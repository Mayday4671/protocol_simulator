# 流程联调工作区改进

依据：原始开发文档和用户 2026-10-15 反馈。协议模拟器用于按任意已录入 UDP 协议主动发送、被动接收并配合对端完成交互测试。运行时不应离开流程页才能看到实际信令。

## 本次范围

1. 常驻运行栏：发布状态、运行端点、对端地址、启动操作及具体不可运行原因。唯一匹配的已启动端点自动选择，仍保留显式更改入口。
2. 节点配置：从绑定 XML 协议选择信令、编辑字段值、由 Rust 预览编码与解析；缺少变量时列出缺项。预览不发送、不创建事务、不修改业务状态。
3. 当前运行：就地展示真实 TX/RX、等待和失败，选中报文直接查看 HEX、十进制、Bit 和中文解析。预览与实际收发明确区分。
4. 后端按运行实例/节点关联真实报文，查询隔离项目和实例；不能用时间或端点近似判定属于哪次运行。兼容旧日志。
5. 保留草稿必须发布、唯一响应匹配、真实 Rust UDP 和已确定 MUSP 业务规则，不放宽规则制造“成功”。

## 分工与验证

- 后端通信：network/flow_host/persistence/application 的报文关联及查询；有限真实 UDP 回归。
- 协议预览：独立 flow_preview 模块、复用流程变量解析、通用 XML 目录与预览单测。
- 前端：Flows 和独立工作区组件、可见启动条件/预览/实时记录的行为测试。
- 集成：类型和命令接线、独立测试数据目录启动桌面实例、普通主动/被动交互桌面验收、NSIS 打包和安装验证。

不执行高频压测，不操作用户当前未保存的流程，不将本机测试流量描述为外部设备验收。
