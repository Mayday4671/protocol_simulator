# 变更记录

## 0.1.0 — 2026-10-15

首次本地桌面实现，面向 Windows 10/11 x64。以下列出代码功能，不替代安装及性能验收报告。

- 建立 Tauri 2 / Rust / React 19 工程，提供七个业务页面与系统设置，支持暗浅主题、本地项目和系统选择。
- 将原生标题栏与项目工具栏合并为一条，支持真实窗口拖动、双击最大化、最小化、还原与关闭；分栏宽度按项目和页面保留。
- 清理八个页面的标题副文案、页脚口号、重复介绍和装饰标签；保留字段单位、状态、操作前提及错误信息。
- 增加本机联调录入脚本：导入34条MUSP v0.8信令，执行五设备配置、注册和三轮心跳，保存实际UDP报文与解析结果。
- 支持 XML DSL 草稿编辑、共享结构、重复数组、位字段、表达式校验、协议发布快照及实际二进制编码/解析。
- 实现 Tokio UDP 多端点、显式本地应答对端、延迟/丢包/重复/CRC 错误注入、报文入库及 HEX/字段定位。
- 实现真实流程节点执行，涵盖等待、分支、赋值、延迟、循环、并行合并及子流程；运行冻结定义，支持后端暂停/单步/继续和 UI 停止、轨迹查看。
- 完善 PendingRequest 的发送前登记、唯一匹配、业务键校验、超时重试、取消、重复和迟到响应处理。
- 实现配置条目映射、逐条 `AA` 确认、设备三态、注册会话及心跳超时；配置不会重置设备运行状态，普通设备超时离线也会持久化并记入历史。
- 实现按通话隔离的 RX/TX 资源、LOCAL_READY / CONTROL_NOTIFY、控制端与 A/B 主动结束、申请取消及掉线清理；实际发送 `0x74/0x7C` 受理响应与 `0x7A` 清理汇总，UNKNOWN 不自动回池，人工核实须确认并留审计记录。
- 提供七个可复制为独立草稿的模板：五设备配置、单设备五参数配置、无需认证注册、独立认证下发注册、三轮心跳、视频四资源、语音两资源。认证模板在真实 `0x12` 发送后使用内存中的会话 Token 继续注册。
- 支持 SQLite 本地持久化、项目 ZIP 校验/导入/导出、协议 XML 导入/导出和报文 JSON/JSONL/CSV 导出；会话 Token 不作为可恢复运行凭证持久化。
- 增加多协议草稿Tab、跨信令结构复制与引用检查；保存流程草稿后禁止静默启动旧发布版；跨项目查询和操作使用项目校验，防止缓存串源。
- 增加 `--self-test <隔离目录>` 的真实 UDP 安装自测及发行文件 SHA256 校验脚本。

发布限制：无代码签名；NSIS 构建、安装/卸载及干净虚拟机离线安装的最终结果由发布验收记录确认。原始协议讨论稿中的待确认业务解释没有被当作正式规范补造。
